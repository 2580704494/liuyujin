# 数据结构

一行是一段任期，一列是一种属性；同一人物多次任职分行记录。

| 必备字段 | 用途 |
| --- | --- |
| 任期编号、姓名 | 区分任职记录 |
| 开始时间、结束时间 | 定位时间区间 |
| 任期时长 | 比较持续时间 |
| 来源、日期精度 | 保留证据及不确定性 |

可增加当选年龄、出身类别、是否辞职、是否短任期、是否名为Leo、备注。行列数不固定。

原图未提供结构化完整表；本次没有逐人提取或核实历史数据。未知值不填0；进行中的任期保留截止日；过早历史日期可拆为年月日字段及原始文本。
