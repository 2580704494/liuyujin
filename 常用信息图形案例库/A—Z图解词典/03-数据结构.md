# 数据结构

一行一个词条，一列一种属性。

| 字段 | 含义 |
| --- | --- |
| 排序号 | 明确展示顺序 |
| 字母 | 索引入口 |
| 英文词条 | 名称 |
| 发音标注 | 按原图记录，未转录则标待查 |
| 中文释义 | 对原图解释的翻译 |
| 插画对象 | 用什么形象解释词条 |
| 来源 | 整体来源与逐条来源分别记录 |

本例26条记录，按7列示意，加表头为27行×7列；这不是字母表型的固定尺寸。
一个字母可对应多个词条，也可只选部分字母。可增加术语核验状态、来源链接和英文解释等字段。
