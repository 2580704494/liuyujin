## 新案例入库步骤
1. 记录作品、作者、日期与原始来源；确认图片使用许可。
2. 明确每条数据代表什么，再判断主要组织逻辑与辅助形式。
3. 完成报告中的数据结构、图形应用、视觉编码、信息框架和叙事框架。
4. 更新案例索引，并根据新证据修订对应类型的概念总文档。
5. 修订表记录日期、案例依据和变化原因，保留不确定性。

## 更新方式
“实时更新”指每次在本仓库新增或修订案例时，同步维护总文档与索引。仓库本身不会自动监控外部案例或自行改写文档。
