## 02 类型判断与图形分析
**主类型：字母表型；具体形式：A—Z图解词典。**
决定排列位置的是词条的首字母与字母顺序，而非时间、数量、严重程度或地理位置。
阅读路线为A → B → C → … → Z；每个字母对应一个词条。
逐项列出资料也有编目特征，但本例最明确的组织规则是字母序，因此主类型归入字母表型。
它不是词云图：字号并未编码词频或权重；不是HOW-TO：没有顺序操作步骤。
仅出现字母不够：应检查字母顺序是否实际承担内容排序、定位和检索的作用。

## 04 统计图形及应用
本例主要使用图文词条列表、分行网格和字母插画融合，没有呈现人数、比例或变化趋势，不以统计图表为核心。
适用：A—Z动物图鉴、设计术语入门、主题词汇学习海报、按拼音或字母顺序编排的知识卡片。
字母表型不要求数值；若另有词频等数据，需要独立字段和明确图例，不能从装饰字号推断。
分行数量与每行项目数服从排版，不代表统计分类或数值分组。

## 05 视觉编码
| 视觉方式 | 作用 |
| --- | --- |
| 大字母A—Z | 标识索引入口及排列顺序 |
| 蜘蛛、小丑等插画 | 形象解释词条所指对象 |
| 英文词条 | 给出名称 |
| 发音标注 | 帮助阅读词语 |
| 简短解释 | 说明恐惧对象 |
| 重复的图文结构 | 稳定各项信息的位置，方便浏览 |
| 深紫背景、滴落字体等 | 呼应恐惧主题、营造氛围 |

颜色与插画大小主要用于区分、装饰和构图。没有图例说明它们代表恐惧程度、患病人数或常见程度，不能自行赋予统计含义。
字母和图像融合有助联想记忆，但应保持字母及词条可辨认；小字在缩小浏览时可能不易阅读。

## 06 信息框架
总体：标题与导语 → A—Z词条 → 作者及参考来源。
单项：字母＋插画＋名称＋发音标注＋解释。
重复结构让读者理解一项后即可阅读其他项。
字母序支持定位与扫描，并不解释各项的成因、从属关系或严重程度。
图底整体参考来源与逐条证据不是同一层次；归档时保留来源对应关系的不确定性。

## 07 叙事框架
用问题引起兴趣 → 从A逐项探索到Z → 每项认识一种恐惧对象。
读者可以顺序阅读，也可以跳到感兴趣的图像。
A—Z是阅读路线，不是事件发展顺序；排在前面不表示更早、更重要或更常见。
这种“主题探索＋逐项发现”的模式适合知识入门，不是操作教程或临床诊断工具。

## 可复用的判断方法
1. 这些条目为什么这样排列？若因字母或拼音顺序，优先考虑字母表型。
2. 字母实际负责排序和检索，还是仅标注部件？仅标号不足以确定类型。
3. 字号、颜色、插画大小是否有数值图例？没有则不作统计解释。
4. 图形是否必须有数字？不必；词条及对应解释也能构成信息图。

## 对总文档的补充
字母表型以字母或拼音等约定字符顺序组织词条，便于查找、浏览和记忆；可以是图文形式，不必含统计数值，也不必完整覆盖A—Z。
本例是一字母一词条，不是所有字母表型的固定格式。
A、B、C部件编号或步骤标签，不足以构成按字母组织的词典或索引。
