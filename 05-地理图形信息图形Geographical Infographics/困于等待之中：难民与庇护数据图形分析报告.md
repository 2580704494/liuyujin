# 《困于等待之中：难民与庇护数据》图形分析报告

> 主类型：地理型。形式：三角形单位网格统计地图＋环形单位数量图。2026-11-19经用户确认入库。分析依据用户提供图片；原始数据口径、统计时点及中间国家角色尚待核验。

- 报刊与出版日期：South China Morning Post（《南华早报》），2020年8月15日（据图）。

- 数据来源标注：Migration Data Portal、UN Refugee Agency。本次未访问原始来源，也未提取完整国家数据。

- 中间彩色三角形模块展示与等候庇护有关的国家数据；外围灰色环形模块展示部分国家接收的登记难民人数。
- 两模块人群与指标不同，不直接相加。中间国家究竟是来源国、等候所在国还是其他归属，需核验原始数据，不能据国家标签擅自确定。

## 02 类型判断与图形分析
**如果只能归一类，归入05—地理型信息图形。**
主要按国家和地区组织，回答“哪些国家人数多、它们属于哪个地区”。
按欧洲、非洲、美洲、亚洲／太平洋／中东等区域布局，并保留部分大致地理关系。
国家由等大三角形拼成，图块面积主要表达统计数量；轮廓、距离和位置经过调整。
具体称为单位网格统计地图，具有变形地图特征。图块大不表示国土面积大。
国家条目具有编目特征，但整体的区域分组与大致国家定位支持以地理型归档。
没有连续时间序列；环形交叠不表达迁移路径，不能当作流向图。

## 03 数据结构
一行记录“一个国家＋一个指标＋一个统计时点”；不同指标分开保存。

| --- | --- | --- | --- | --- | --- | --- |

这只是结构示意，不是真实国家数据。
建议再加国家代码、指标定义、原始值、显示值、四舍五入规则、符号单位、余数绘制规则、缺失状态等。
每个完整三角形代表1,000名寻求庇护者；每条短线代表1,000名难民（据图例）。数值不一定恰为1,000的整数倍，不能通过数完整符号替代原始值。
同一国家的两类人数含义不同，不能只保留“国家＋人数”。
原图术语说明与原始统计定义需分别记录，不把图形分析当作法律身份认定。
未知值不填0；小数值仍需保留。出版时间、统计时间分列，防止把2020年版面当作当前数据。
本次不制作未经核实的完整数据表，也不推断迁移来源—目的地矩阵。

## 04 统计图形及应用
| 图形 | 功能及限制 |
| --- | --- |
| 三角形单位图 | 一个完整三角形代表1,000名寻求庇护者 |
| 单位网格统计地图 | 按国家和大致区域排布单位图，比较数量与分布 |
| 环形单位图 | 每条短线代表1,000名难民；人数由单位数量表达 |
| 小数值列表 | 补充部分人数较少国家的具体数字 |

10个完整三角形按图例对应约10,000人。
不足1,000人的记录有小片状符号与数字，具体余数是否按面积严格切分需核验；精确值读数字。
外围环形不是普通饼图，不能从圆面积直接反推人数。
适用：国家或地区的人口、病例、资源数量比较。前提是单位、人群范围、统计时间和地区角色明确。
若要求精确国家排名，可辅以统一尺度的条形图。不能从变形图上测实际国土面积、距离或方向。

## 05 视觉编码
| 视觉方式 | 作用 |
| --- | --- |
| 三角形数量 | 人数规模 |
| 国家单位图块总面积 | 随单位数量变化，表达统计数量 |
| 区域与国家相对位置 | 帮助大致定位与分组，不是精确地理测量 |
| 彩色国家图块 | 帮助区分相邻国家；没有明确证据表明颜色编码风险或其他等级 |
| 国家名称与数值 | 提供身份和具体人数 |
| 灰色短线 | 依单位图例表达接收的难民人数 |
| 引线与注释 | 连接说明和目标图形 |

不能自行把红色、黄色或深浅解释为危险程度、收入或严重程度。
环形相互交叠不是迁移流向，也不是重叠人群数量的编码。
国家图块轮廓与环形布局服务于排版和数量表达，不能据其交叠推断国家间联系。

## 06 信息框架
标题与背景 → 术语说明 → 单位图例 → 分地区国家数据 → 部分接收国数据 → 来源。
两个不同问题同版呈现：等候庇护相关人数如何分布；哪些国家接收了较多登记难民。
必须分别识别人群、指标、国家角色和统计时点。
图中分别说明寻求庇护者与难民，分析中不将两类记录混为同一指标。中间国家角色保留待核验。

## 07 叙事框架
提出长期等待的处境 → 用大量重复单位展现规模 → 按地区观察国家差异 → 对照接收国数据。
小单位将抽象人数转化为可视的规模感；区域布局支持按需查看。
这是历史统计时点的分布与对比，不是连续时间变化，也没有展示具体人员迁移路线。
不能仅据图中两模块并置推断来源国与接收国之间的人员对应。

## 可复用的判断方法
1. 位置是否帮助找地区和国家？本例是。
2. 图块大小代表什么？本例代表统计数量，不是国土面积。
3. 一个符号代表多少？先读图例，再比较数量。
4. 不同模块是否同一指标？本例不是，不直接相加。
5. 连线、交叠是否有流向定义？本例没有，不作迁移路线解释。

## 对总文档的补充
地理型可采用变形地图与单位网格，不必保持真实国土面积和轮廓。
分析时区分数量编码与地理底图面积，记录单位、余数处理、国家角色与统计时点。
有国家标签不自动成为地理型，地理定位或区域关系需实际参与组织。
交叠或环形排版不自动表达流向；不同人群指标不得混加。
